# @ride-app/shared-types

TypeScript contracts shared between services and the web app: Kafka event payloads (`events.ts`), the trip DTO returned by trip-service plus `RATING_TAGS` (`trip.ts`), and a legacy user type (`user.ts`). Types only, plus one constant; no runtime dependencies.

Full documentation: [docs/README.md](docs/README.md). Topic list: [docs/event-catalog.md](docs/event-catalog.md).
