# @ride-app/shared-location

Driver live state in Redis (key layout, ping validation, online/offline/trip transitions, nearby search, staleness sweep), plus geo helpers (`haversineMeters`) and the served cities and service area. Written by realtime-gateway, read and maintained by location-service, used by trip-service, mapping-service, pricing-service and the web app.

Full documentation: [docs/README.md](docs/README.md).
