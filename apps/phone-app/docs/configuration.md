# Configuration

The app is configured at compile time with `--dart-define` values, normally from a file: `flutter run --dart-define-from-file=env/<name>.json` (`make dev-mobile ENV=<name>`). They are read in `lib/core/config/env.dart` (`Env`) with `String.fromEnvironment`; nothing is read at runtime.

## Every define

| Define | Default in `env.dart` | Meaning | Read by |
|---|---|---|---|
| `API_MODE` | `gateway` | `gateway`: every request to `API_BASE_URL`. `host`: each `/api/<prefix>` to its service's port on `HOST_BASE` | `Env.endpoints` → `endpointsProvider` |
| `API_BASE_URL` | `http://localhost:8000` | Kong or production base URL (gateway mode) | same |
| `HOST_BASE` | `http://localhost` | host for the per-service ports (host mode) | same |
| `WS_URL` | `ws://localhost:3000` | realtime-gateway (Socket.io), never behind Kong | `socketLinkProvider` |
| `TILE_URL` | empty | light raster tiles `{z}/{x}/{y}` (`{r}` enables retina); empty = OpenStreetMap's public tiles (development only) | `tileStyleProvider` |
| `TILE_ATTRIBUTION` | `© OpenStreetMap contributors` | credit drawn on the map | same |
| `TILE_URL_DARK` | empty | dark tiles; empty = CARTO `dark_all` (development only) | same |
| `TILE_ATTRIBUTION_DARK` | `© OpenStreetMap contributors © CARTO` | dark credit | same |
| `DEV_LOGIN` | `off` | `on` shows the dev sign-in panel, **only in debug builds** (`Env.devLoginOn = kDebugMode && on`) | WelcomeScreen |
| `FAKE_LOCATION` | `off` | `on` uses `FakeLocationSource` and shows the dev location panel; always on for Linux desktop (`Env.fakeLocationOn`) | `locationSourceProvider`, driver screens |
| `APP_LINK_HOST` | `app.anbessa.et` | public host for https app links. **Not read anywhere in `lib/`**; the Android manifest hardcodes `app.anbessa.et` | — |
| `FIREBASE_API_KEY` | empty | Firebase option | PushService |
| `FIREBASE_APP_ID` | empty | Firebase option | PushService |
| `FIREBASE_PROJECT_ID` | empty | Firebase option | PushService |
| `FIREBASE_SENDER_ID` | empty | Firebase messaging sender id | PushService |

Push is initialised only when all four `FIREBASE_*` values are non-empty and the platform is Android or iOS (`Env.firebaseConfigured`). None of the env files sets them; pass them with extra `--dart-define`s. Do not commit their values.

`Env.devApiBase` (host mode: `HOST_BASE:3001`, else `API_BASE_URL`) is defined but not used; dev sign-in calls go through the normal `ApiClient` routing.

## Values per env file

Absent from a file = the `env.dart` default applies.

| Define | `dev-host` | `dev-emulator` | `dev-kong` | `stack` | `staging` |
|---|---|---|---|---|---|
| `API_MODE` | host | host | gateway | gateway | gateway |
| `API_BASE_URL` | (default) | (default) | `http://localhost:8000` | `http://localhost:8000` | `https://api.staging.anbessa.et` |
| `HOST_BASE` | `http://localhost` | `http://10.0.2.2` | (default) | (default) | (default) |
| `WS_URL` | `ws://localhost:3000` | `ws://10.0.2.2:3000` | `ws://localhost:3000` | `ws://localhost:3000` | `wss://ws.staging.anbessa.et` |
| `TILE_URL` | empty | empty | empty | empty | `https://tiles.staging.anbessa.et/styles/basic/{z}/{x}/{y}.png` |
| `TILE_URL_DARK` | (default, empty) | (default) | (default) | (default) | (default, empty → CARTO) |
| `DEV_LOGIN` | on | on | on | off | off |
| `FAKE_LOCATION` | on | off | on | on | off |
| `APP_LINK_HOST` | (default) | (default) | (default) | (default) | `app.anbessa.et` |

Notes:

- `dev-host`: `make dev-services` on this machine, no Kong. On Linux the fake location is forced anyway.
- `dev-emulator`: the same backend from the Android emulator (`10.0.2.2` is the host machine); real (emulated) GPS.
- `dev-kong`: `make dev-services` behind `make dev-gateway`. The dev Kong config (`infra/kong/kong.dev.yml`, generated by `scripts/kong-dev-config.sh`) routes `/api/dev`, so the dev panel works.
- `stack`: `make stack-up` through Kong; `DEV_LOGIN` is off because that Kong does not route `/api/dev` (docs/development/README.md).
- `staging`: no dark tile URL, so dark mode falls back to CARTO's public tiles, which `env.dart` describes as development only.
- Cleartext `http://` and `ws://` only work in debug Android builds (`android/app/src/debug/AndroidManifest.xml`).

## Values fixed in code

| Value | Where |
|---|---|
| Connect timeout 10 s, receive 20 s, retry delays 500 ms / 1 s / 2 s, user agent `anbessa-app` | `ApiClient` defaults |
| Socket reconnect delay 1 s → 16 s | `SocketIoLink` |
| Client config refresh 60 s | `ClientConfigController` |
| Nearby cars poll 10 s; driver position poll 5 s; ETA refresh 30 s; pay and top-up polls 5 s; driver session check 60 s | see architecture.md |
| Rider cancel fee shown: 30 ETB (`_cancelFeeMinor = 3000`) | `rider_trip_screen.dart` |
| Free waiting 3 min, no-show after 5 min, arrival hint 150 m / 300 m | `driver_trip_screen.dart` |
| Store links | `UpdateRequiredScreen` |
